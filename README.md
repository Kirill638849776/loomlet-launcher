## Что это

Loomlet Launcher — это небольшая программа, которая запускает Minecraft с модами Fabric.  
Она сама проверяет, всё ли готово к игре, и помогает, если чего-то не хватает.

## Что умеет

- 🎮 Запускает Minecraft через `gradlew runClient`
- ☕ Ставит Java 25, если её нет
- 📦 Скачивает файлы Gradle с GitHub
- 🛑 Выключает игру одной кнопкой
- 📜 Показывает лог игры прямо в окне
- ⌨️ `Enter` — играть, `Escape` — выйти

## Как играть

1. Скачай репозиторий и запусти `python main.py`
2. Нажми «УСТАНОВИТЬ»
3. Дождись, пока Java и Gradle станут зелёными
4. Введи ник → «ИГРАТЬ»

## Где моды

Папка `files-gradle/run/mods` — кидай туда `.jar` файлы модов.
